# LA-Sistemas ERP

Sistema de gestão empresarial modular, preparado para crescer com a operação da LA-Sistemas.

## Estado atual

O backend possui autenticação, cadastros, produtos, estoque, compras, vendas e caixas simultâneos por vendedor e computador. Cada caixa armazena seus movimentos próprios e gera relatório no fechamento; também há consolidado diário por computador. A interface visual será criada posteriormente a partir do modelo PowerPoint do projeto.

Consulte [a documentação do backend](backend/README.md) para executar a API e conhecer os endpoints.
